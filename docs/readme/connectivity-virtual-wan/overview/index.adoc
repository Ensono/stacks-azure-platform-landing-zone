== Overview

The **Stacks Azure Platform Landing Zone Connectivity Virtual WAN** module deploys a Virtual WAN network topology using the below Azure Verified Modules:

https://registry.terraform.io/modules/Azure/avm-ptn-alz-connectivity-virtual-wan/azurerm/latest[Virtual WAN]

It supports single or multi-region deployments with automatic IP allocation and CAF-compliant naming.

Virtual WAN provides a fully managed hub infrastructure with automatic any-to-any routing, integrating VPN and ExpressRoute gateways directly within the virtual hub. Each hub has a companion sidecar VNet for services such as Azure Bastion, DNS Resolver, and private endpoints that cannot be placed inside the virtual hub itself.

=== Module Chain

----
resource_groups → virtual_wan
----

1. **resource_groups** — Deploys resource groups per hub region using `for_each` from configuration
2. **virtual_wan** — Deploys the Virtual WAN, virtual hubs, firewall, bastion, DNS, and gateways using https://registry.terraform.io/modules/Azure/avm-ptn-alz-connectivity-virtual-wan/azurerm/latest[avm-ptn-alz-connectivity-virtual-wan]

=== Prerequisites

* Terraform >= 1.12
* AzureRM provider >= 4.0
* AzAPI provider >= 2.0
* Azure subscription for connectivity resources
* Management Landing Zone deployed (for Log Analytics integration)
