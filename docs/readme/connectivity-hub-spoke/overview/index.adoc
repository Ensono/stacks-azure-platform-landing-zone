== Overview

This module deploys hub virtual networks using Azure Verified Modules (AVM). It supports single or multi-region deployments with automatic IP allocation and CAF-compliant naming.

=== What This Module Deploys

. **Hub Virtual Networks** — Per-region hub VNets with Azure Firewall, DNS, and platform services
. **Network Security** — Firewall policies, route tables, NSGs, and DDoS protection
. **Hybrid Connectivity** (optional) — VPN and ExpressRoute gateways
. **Monitoring** — Diagnostic settings, metric alerts, and Azure Monitor Private Link Scope

=== Prerequisites

* An Azure subscription designated as the **connectivity subscription**
* Terraform ~> 1.12, AzureRM ~> 4.0, AzAPI ~> 2.0
* Management module deployed first (for Log Analytics integration via remote state)
