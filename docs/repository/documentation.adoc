== Documentation System

=== Two Documentation Sets

This repository maintains **two separate documentation sets**:

==== 1. Repository Documentation

- **Location:** `docs/repository/index.adoc` (and included files)
- **Audience:** Developers working on this repository
- **Purpose:** Build system, development workflow, contribution guidelines
- **Distribution:** Not included in the module package

==== 2. Module Documentation

- **Location:** `docs/readme/<module>/index.adoc` (and included files)
- **Audience:** Users consuming the Terraform module
- **Purpose:** Module usage, API reference, examples
- **Distribution:** Packaged as `README.md` in the zip file

=== Documentation Workflow

The module documentation follows two paths:

==== Module README (API reference)

The `README.md` in each module root is maintained with a hand-written usage guide and auto-generated API reference. `terraform-docs` injects content between `<!-- BEGIN_TF_DOCS -->` and `<!-- END_TF_DOCS -->` markers.

[source]
----
1. Edit README.md usage sections directly (above the markers)
2. terraform-docs injects API docs from Terraform source
   └── src/<module>/README.md (between markers)
3. Run: eirctl docs (from module root)
----

==== Build pipeline (distributable package)

The `eirctl build` pipeline converts the AsciiDoc sources into a distributable zip:

[source]
----
1. AsciiDoc source files
   └── docs/readme/<module>/index.adoc (includes tfdocs.adoc)

2. terraform-docs generates API docs
   └── docs/readme/<module>/tfdocs.adoc

3. AsciiDoc → DocBook → Markdown conversion
   └── outputs/module/README.md

4. Package with module
   └── outputs/<module>-<version>.zip
----

=== Editing Documentation

==== Module Documentation

[source,bash]
----
# Edit the module documentation
vim docs/readme/<module>/index.adoc

# The index.adoc includes tfdocs.adoc which is auto-generated
# Build to regenerate
eirctl build
----

==== API Documentation

API documentation is **auto-generated** from Terraform code using `terraform-docs`:

- Configuration: `src/<module>/.terraform-docs.yml`
- Output: Injected into `src/<module>/README.md` (between markers)
- Format: Markdown tables
- Includes: Requirements, Providers, Modules, Resources, Inputs, Outputs

To update API docs:

1. Modify Terraform files in `src/<module>/deploy/terraform/`
2. Run `eirctl documentation` from the module root (e.g., `src/management/`)

==== Repository Documentation

[source,bash]
----
# Edit repository documentation
vim docs/repository/*.adoc

# These files are NOT included in the module package
# They're for repository development only
----
